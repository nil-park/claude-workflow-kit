- 한 낱말이 서로 다른 동작이나 대상을 여럿 맡는다
  - 서로 다른 동작을 한 동사로 받는다
  - 서로 다른 대상을 한 명사로 받는다
  - > 좌표를 잡는다 / 후보로 잡고 / 임계를 잡았다 / 예외를 잡아 기록한다
    - 설정, 검출, 임계 지정, 예외 처리가 한 동사로 수렴해 무엇을 하는지가 문장에서 사라진다.
  - > 후보의 오탐을 거른다 / 화면이 바뀌기 전 프레임을 거른다 / 중복 추가를 걸러낸다 / 반복 항목을 걸러 파라미터만 남긴다
    - 후보 제외, 프레임 건너뛰기, 중복 차단, 값 추출을 모두 ⁌거른다⁍로 적어, 어느 동작인지 읽는 사람이 앞뒤 문맥으로 짐작해야 한다.
  - > 링버퍼에 프레임을 담는다 / 응답에 `isPlaying`을 담는다 / 감지 목록에 언어를 담는다 / 버튼 안에 꼬리표를 담는다
    - 저장, 필드 포함, 목록 추가, 화면 배치를 한 동사가 맡아, 데이터를 다루는 코드인지 화면을 그리는 코드인지조차 드러나지 않는다.
  - > 고칠 자리마다 판정을 적는다 / 그 자리에서 가장 짧은 표현 / 파일 안의 자리
    - 낱말과 문장, 파일 안의 위치를 한 명사가 모두 받는다.
