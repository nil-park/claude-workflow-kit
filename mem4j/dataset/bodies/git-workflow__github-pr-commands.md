- **커밋이 없으면 PR을 열 수 없다.**
  - draft PR은 설계 단계의 첫 커밋과 함께 연다.
  - 설계 단계를 두지 않기로 했으면 구현 단계의 첫 커밋과 함께 연다.
  - PR을 열려고 빈 커밋을 만들지는 않는다.

```
gh pr create --base "<origin 기본 브랜치>" --draft -a @me \
  -t "제목" --body-file <본문 파일>
```

- 본문은 `gh pr edit --body-file <경로>`로 고치고, Ready로 전환할 때에는 `gh pr ready`를 실행한다.
- 본문은 파일로 쓰고, `--body-file`로 그 파일의 경로를 넘긴다.
  - 여러 줄 텍스트를 명령줄에 직접 붙여 넣으면 이스케이프 실수가 생기기 쉽다.
