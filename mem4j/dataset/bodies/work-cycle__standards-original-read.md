- `docs-standards`와 `coding-standards` 스킬의 조항은 원문에서 확인한다.
  - 라운드 기록, 이전 턴의 정리, 컨텍스트 압축 요약 등의 요약본으로 원문을 대신하지 않는다.
  - 요약본에는 목적과 예외 조건이 빠지므로, 남은 제한 사항만 기계적으로 확인하게 된다.
- 작성 단계와 리뷰 라운드 모두에서, 기준을 적용하기 직전에 대상 텍스트를 원문의 해당 조항과 대조한다.
  - 컨텍스트 윈도우에 전문이 이미 올라와 있으면 그 내용을 원문으로 인정한다.
  - 다음 경우에만 도구로 해당 파일을 다시 읽는다.
    - 이번 세션에서 해당 파일의 전문을 아직 읽지 않았을 때
    - 파일을 마지막으로 읽은 뒤 변경 사항이 생겼을 때
    - 컨텍스트가 압축되었을 때
    - 훅이나 내가 다시 읽으라고 지시했을 때
- 이 규칙은 나에게 하는 보고에는 적용하지 않는다.
  - 보고는 계속 요약해서 전한다.
