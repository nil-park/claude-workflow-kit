# 목적

- 이 도메인에서 최소한 이것은 꼭 챙겨라는 의미.
- **이 카탈로그는 전부가 아니다.** 여기 없는 관점도 너의 컴퓨터 공학적 지식에서 꺼내서 써야한다.

# 기준 카탈로그

## 공통

- **실패 경로와 경계 조건**: 빈 입력, 에러 경로, 잘못된 변수, 놓친 엣지 케이스
- **에러 억제**: 타입 체커나 린터가 잡아낸 문제에 대한 무분별한 억제
  - 라이브러리의 구조적 제약처럼 근본 해결이 불가능할 때만 억제하고, 이유를 주석으로 남긴다.
- **메모리 누수**: 해제하지 않은 구독·리스너, 상한 없는 캐시·컬렉션, 취소하지 않은 타이머·태스크, 스코프를 넘어 잡힌 참조, 닫지 않은 파일·소켓·DB 커넥션
- **순환 의존성**: 새 import가 만드는 순환, 하위 레이어의 상위 되참조, 배럴 파일로 가려진 순환
- **시크릿과 입력 신뢰**: 하드코딩된 자격증명, 로그에 찍히는 토큰·개인정보, 검증 없이
  쿼리·명령·경로로 흘러가는 입력
- **인코딩 미지정**: 인코딩 없는 파일 입출력, charset 없는 바이트↔문자열 변환과 Content-Type,
  한글을 `\uXXXX`로 escape하는 JSON 직렬화
  - 한글은 NFC로 정규화한다. macOS는 NFD를 만든다.
- **시각 처리**: 타임존 없는 naive datetime, 로컬 타임존 기준 저장·비교, 오프셋 없이
  직렬화한 시각, DST와 날짜 경계
  - 저장과 전송은 UTC, 표시할 때만 로컬로 바꾼다.
- **중복 코드**: 복붙한 블록, 이미 있는 함수를 모르고 다시 구현한 것
  - 같이 바뀌지 않을 코드는 겉이 같아도 합치지 않는다.
- **파일 길이**: 200줄을 넘으면 쪼갤 자리를 찾는다
  - 쪼갰을 때 상호참조나 순환참조가 생기는 자리는 그냥 둔다. 길이가 긴 것보다 순환이 나쁘다.
- **설정 항목 과다**: 한 곳에서만 쓰는 값을 설정으로 뺀 것, 기본값 말고는 아무도 바꾸지
  않는 항목
  - 범용 소프트웨어가 아니라면 대부분 스테이징 지정자와 하드코딩된 상수 매핑으로 해결된다.
- **테스트 실효성**: 실패 경로와 경계 조건에 대한 테스트
  - 판정은 하나로 한다. 구현의 어느 줄을 망가뜨리면 이 테스트가 빨개지는가.
  - 뺄 것: 모킹이 돌려준 값을 그대로 확인, 구현을 베낀 기대값, 자명한 구현에 붙인 테스트,
    예외만 안 나면 통과하는 테스트, `assertTrue(x)`나 not-None처럼 잘못된 값도 통과하는 단정
- **잔여물**: 디버그 출력, 죽은 코드, 주석 처리된 코드, 방치된 TODO
- **군더더기 주석**: 자명한 코드에 달린 주석, 타입·이름이 이미 말하는 것을 옮겨 적은 주석
- **네이밍**: 하는 일과 어긋난 이름, 뭉뚱그린 이름(`data`, `info`, `manager`), 주변과 다른 표기 규칙
  - 주석을 달아야 읽히면 이름을 잘못 지은 것이다. 주석 대신 이름을 고친다.
  - 파일 이름도 같다. 트리만 찍어 보고 원하는 기능을 찾을 수 있어야 한다.

## 클라이언트 (HTTP/RPC/외부 서비스 의존)

- **예외 처리 누락**: 타임아웃 미설정, 상태 코드를 보지 않고 본문 파싱, 네트워크 예외를
  그대로 흘려보냄
- **재시도 정책**: 일시적 실패에만 재시도, 지터를 넣은 백오프, 시도 횟수와 총 시간 상한
  - 멱등하지 않은 요청은 재시도하지 않는다.

## 서버

- **커넥션 풀**: 요청마다 새로 만드는 커넥션, 반납 누락, 획득 타임아웃 없음, 워커 수와
  어긋난 풀 크기
- **동시성 상한**: 상한 없이 뜨는 태스크·코루틴, 크기 없는 큐, 밀려도 계속 가져오는 컨슈머
- **인증과 인가**: 인가 검사가 빠진 엔드포인트, 소유자 확인 없는 리소스 접근, 클라이언트가
  보낸 권한 값을 그대로 신뢰

## 데이터베이스

- **인덱스를 타지 않는 쿼리**: 풀 스캔, 인덱스 좌측 접두사를 안 쓴 조건, 컬럼을 함수로 감싼
  WHERE, 선택도 낮은 인덱스
- **쿼리 타임아웃**: statement timeout 미설정, 락 대기 상한 없음
- **N+1 쿼리**: 루프 안에서 도는 조회, 지연 로딩으로 숨은 반복 쿼리
- **상한 없는 결과 집합**: LIMIT 없는 SELECT, 페이지네이션 없이 전량을 메모리로,
  조회 구간(start/end)을 필수로 받지 않는 API
  - 구간을 받더라도 최대 폭에 상한이 없으면 마찬가지다.
- **트랜잭션 범위**: 트랜잭션 안에서 부르는 외부 API, 사용자 입력을 기다리는 트랜잭션
- **마이그레이션**: 테이블 전체를 잠그는 DDL, 되돌릴 수 없는 파괴적 변경

## 런타임 (JVM, Go 등 장기 실행 프로세스)

- **메모리와 GC 설정**: `-Xmx`나 `GOMEMLIMIT` 미설정, 지연에 민감한데 GC를 기본값으로 방치

## 관측성 (로그·지표·추적)

- **로그 포맷**: 서버에서 평문 로깅, 로컬에서 JSON 로깅, 로컬에서 severity 컬러링 누락,
  오프셋 없는 타임스탬프
  - 프레임워크나 라이브러리가 자기 포매터로 찍는 로그가 섞이지 않는지 함께 본다.
- **로그 레벨**: 전부 info, 삼키면서 debug로 낮춘 에러, 정상 경로에 박힌 error
  - 외부 의존성 때문에 생기는 불안정은 warning, 우리 쪽 결함은 error다.
  - 라이브러리는 레벨 기준이 다르다. 재시도로 회복한 실패를 error로 찍는 것이 흔하다.
  - GCP Cloud Logging은 `level`이 아니라 `severity` 필드를 본다.
- **로그 홍수**: `/healthcheck`·`/metrics` 로깅, 루프 안에서 찍는 로그, 요청 하나에 여러 줄
- **실패가 보이는 지표**: 평균만 있고 분포가 없는 지연, 성공만 세는 카운터, 잘못 설정된 버킷 구간
- **추적 맥락 전파**: 서비스 경계를 넘으면 끊기는 요청 ID, 비동기 태스크로 넘어가지 않는 컨텍스트

## 인프라

- **최소 권한 위배**: 와일드카드 IAM 정책, 필요 이상으로 열린 네트워크, 환경 간 롤 재사용
- **비용 귀속 레이블**: 비용 분할에 쓰는 레이블·태그 누락
