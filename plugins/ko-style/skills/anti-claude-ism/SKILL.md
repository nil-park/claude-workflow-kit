# 클로디즘 걷어내기

대상 텍스트에서 Claude가 한국어를 쓸 때 되풀이하는 문형을 찾아, 문맥에 맞는 한국어로 다시
쓴다. 영어 단어를 그대로 옮긴 서술어, 무생물에 붙인 사람 동사, 설명 대신 넣은 비유, 지어낸
낱말, 주어와 서술어가 어긋난 문장이 대상이다.

낱말과 표기는 `ko-style` 훅이 사전으로 탐지하므로 여기서 다시 다루지 않는다. 사전에 없는 문형과,
정규식으로는 탐지되지 않는 문장 구조를 읽어서 판정한다.

## 대상

- 지정받은 범위 안에서만 고친다. 지정이 없으면 이번 작업에서 새로 쓰거나 고친 한국어 텍스트가
  대상이다.
- 문서, 소스 코드 주석, 독스트링, 커밋 메시지, 이슈와 PR/MR의 제목과 설명을 모두 다룬다.
- 사람이 직접 쓴 텍스트에도 같은 기준을 적용한다. 작성자에 따라 기준을 바꾸지 않는다.

## 절차

1. `references/word-level.md`와 `references/sentence-level.md`를 원문으로 읽는다. 이전 턴의
   요약이나 기억으로 대신하지 않는다. 판정 근거는 목록에 적힌 문장 자체다.
2. 대상 텍스트를 처음부터 끝까지 읽는다. `grep`으로 낱말만 검색하면 문장 단위 결함이 전부
   빠진다. 발췌 검색은 낱말 목록을 재확인할 때만 쓴다.
3. 고칠 낱말과 문장마다 무엇이 잘못됐는지 적고, 문맥에 맞게 다시 쓴다. 목록에 있으면 그 판정
   이름을 쓰고, 목록에 없는 결함도 같은 방식으로 고친다.
4. 고친 위치와 판정 이름을 보고한다. 고치기 전후 문장을 나란히 늘어놓지 않는다.

## 판정 기준

- **목록에 오른 표현이라도 그대로 쓸 때가 있다.** 쓰인 문장에서 그보다 짧고 정확한 말이 없으면
  의인화도 남긴다.
- **고친 결과가 목록의 다른 항목이 되지 않는지 확인한다.** "낸다"를 피하다가 문단 전체가
  "본다"로 몰리기 쉽다.
- **무엇으로 바꿀지는 문맥에서 정한다.** 목록에는 대체 표현이 없다.
