# Claude 문체 — 낱말 단위로 걷어낼 표현 목록

한 리포의 한국어 문서·주석·독스트링을 전부 훑어 모았다. 사람이 쓰지 않는 문형, 직역, 지어낸 낱말,
같은 상투구의 반복이 대상이다. 개별 판단은 문맥에서 하되, 아래에 모인 것은 전부 한 번은 다시 봐야 한다.

문장 단위 결함은 [sentence-level.md](sentence-level.md)에 있다.

## 1. 반환을 "낸다"로 뭉갠 서술어

`return`을 전부 "낸다"로 옮겼다. 무엇을 어디에 어떻게 돌려주는지가 사라지고, 한 문단에 같은 서술어가
서너 번씩 겹친다. 값을 돌려줄 때는 "반환한다", 계산해 얻을 때는 "구한다", 판정한 결과일 때는
"판정한다"를 구분해 쓴다.

- 낸다 / 함께 낸다 / 그대로 낸다 / 곧장 낸다
- 최고 점수를 낸다
- 최고 비율과 그 좌상단을 낸다
- 그 방향을 낸다
- 0을 낸다 / `None`을 낸다 / 점수 0에 포즈 `None`을 낸다
- 붙인 이름을 낸다 / 그 이름을 낸다
- 푼 파일 수를 낸다
- 보이는 픽셀만으로 비율을 낸다
- 갱신된 관측을 낸다
- 조작을 순서대로 낸다
- 격자 포인트를 낸다
- 프레임과 그때의 격자, 계단 템플릿을 낸다
- 이펙트가 가린 열을 낸다
- 계단 5칸만 낸다
- 발밑을 낸다
- 블록 줄 (명사구로 끝낸 독스트링 요약)

## 2. 확인·판정을 "본다"로 뭉갠 서술어

`check` / `see` / `treat as`가 전부 "본다"가 됐다. 측정인지 비교인지 판정인지가 문장에서 사라진다.

- ~인지 본다 / ~는지 본다 / 그래서 ~하는지 본다
- 색을 본다 / 두 칸의 색을 봐
- 흔적을 보지 않는다 / 흔적을 안 보면
- 멎은 것으로 본다 / 오탐으로 본다 / 계단으로 본다 / 가려진 칸으로 본다
- 없다고 본다 / 게임 오버로 본다 / 중복으로 본다
- 모양만 봐 / 색을 함께 봐 / 윤곽선 세기를 함께 봐
- 겹치는지 보고 / 맞는지 먼저 본다
- 이 분리가 서는지를 본다
- 테스트가 ~ 본다 (문서·테스트 독스트링 전반)

## 3. 영어 낱말을 그대로 옮긴 것

- **은행** — `bank`의 직역. 한국어에서 이 뜻으로 쓰지 않는다. "자세 은행", "이번 세션의 활성 자세 은행",
  "학습한 은행", "기존 은행", "다른 은행의 자세".
- **당첨 포즈** — `winning`의 직역. "당첨 포즈의 방향", "당첨 포즈 좌상단".
- **관문** — `gate`. "사람이 개입하는 관문이다".
- **게이트** — 음차. "방향 일치도 게이트 없이".
- **콘솔 홍수** — `flood`. "콘솔 홍수를 억제한다".
- **값싸게 / 값싼** — `cheap`. "값싸게 확인해", "값싸게 판정한다", "값싼 발동 판정".
- **강인하다** — `robust`. "가림에 강인하다", "배경에 강인한", "오탐에 강인하고".
- **조용히** — `silently`. "조용히 버린다", "조용히 무시한다", "조용히 인식을 망가뜨리므로".
- **예외를 삼킨다** — `swallow`. "예외를 삼키고", "예외를 삼킨다".
- **바닥으로 둔다** — `floor`. "log_level을 바닥으로 둔다".
- **~쪽으로 보수적이다** — `conservative`. "중복을 남기는 쪽으로 보수적이다".
- **거꾸로 import한다** — `reverse`. "control을 거꾸로 import하지 않게", "character_finder를 거꾸로 알지 않게".
- **~에 놓인다** — `lie in`. "0.45 이상에 놓인다", "0.005 이하에 놓여", "그 사이로 잡았다".
- **접는다** — `fold`. "소거 보간과 외삽을 접고 멈춘다", "외삽을 접는 데 쓴다".
- **떨어진다** — `fall back`. "학습으로 떨어지지 않는다", "검출 하한 아래로 떨어졌고".
- **떨군다** — `dump`. "한 번에 떨군다".
- **얹는다** — "창 백엔드가 얹는 상위 비트".
- **묶는다** — `bundle`/`zip`. "데이터셋 zip으로 묶는다", "폴더를 다시 묶으면".
- **축을 요구해** — `axis`. "`absdiff_refine`이 템플릿 축을 요구해".
- **덮어** — `cover`. "새 검출이 같은 줄의 기억을 덮어쓰고", "다음 주기에 덮어쓴다".
- **물려받아** — `inherit`. "accept()가 리스너의 타임아웃을 물려받아".
- **가른다** — "배경 칸과 계단 칸을 가르는지", "가로로 갈린다".
- **기동** — 일본어투 한자어. "서버 기동", "기동 메시지", "기동을 이어 간다".

## 4. 의인화

무생물에 사람 동사를 붙였다.

- 이 세션을 **낳은** 설정값
- 배경 칸이 top-1을 **가져가지** 못한다
- 태그는 대개 최근 프레임을 **향하므로**
- 캐릭터는 발밑에 **앉아** / 발밑에 **앉으므로**
- `-2`가 **이김** / 변이별 값이 **앞선다**
- 탭이 늦게 **먹어**
- S 채널이 배경 칸을 **떨어뜨린다**
- 흔적 하한이 배경까지 **주워 담으면**
- 소거 보간이 통째로 **죽는다**
- 방향이 **오염되지** 않는다
- 이 확인은 계단 검출보다 앞서 **돌아**
- 자세 기억이 **비지** 않게 / 은행이 아무 캐릭터와도 **맞지** 않아
- 색 세 채널은 배경이 통과하지 않게 **조이고**, S는 **느슨하게** 둔다

## 5. 설명을 대신한 비유

- **허공** — "허공으로 뒤돌아 죽는다", "캐릭터를 허공으로 보냈다", "없는 turn을 넣어 허공으로 뒤돈다"
- **죽는다 / 죽기 직전** — "죽은 프레임", "죽기 직전 프레임", "죽기 직전 맥락"
- **박는다 / 박아 둔다** — "격자로 박는다", "칸으로 박아 둘 수 없어", "네이티브 픽셀로 박아 둔"
- **굳어 있다** — "격자 y0는 보정 기준 화면의 콘텐츠 위치로 굳어 있어"
- **되민다** — "유지 시간을 지금부터 2초로 되밀어", "되밀고"
- **흔든다** — "coarse를 흔들어 교정을 유도할", "coarse를 흔든 뒤"
- **뭉개진다** — "S 채널이 두 번 뭉개지지 않게", "계단 형상의 뭉개짐을 줄이려고"
- **스냅샷을 뜨고** — "스냅샷을 뜨고 버퍼를 비운 뒤"
- **엉뚱한 화면** — "엉뚱한 화면에서 자동 모드를 켰다가"
- **되레 시끄럽게** — "되레 시끄럽게 만들지 않도록"
- **곁들여 든다** — "최신 프레임 슬롯이 원본도 하나 곁들여 든다"
- **표본을 딴** — "표본을 딴 기기"
- **찍어 보낸다** — "한쪽을 찍어 허공으로 보내지 않는다"

## 6. 지어낸 낱말

- **자리끼움** — "그리기를 건너뛰는 자리끼움" (placeholder를 옮긴 조어)
- **본로직** — "본로직: 매칭 윈도우 좌상단 → 착지점"
- **되뺀다** — "앵커만큼 되뺀 좌상단", "템플릿 폭의 절반을 되뺀다"
- **편다** — `reshape`. "0/255 uint8로 편다", "(C, 1, 1)로 편다"
- **진단거리** — "남길 진단거리가 없다고 보고"
- **밀림** — `drift`. "격자 밀림", "서브픽셀 밀림", "밀림을 흡수한다".
- **채점한다** — `score`. "아는 칸만 채점하므로", "칸 자리에서 한 번 채점해", "변이마다 따로 채점하므로".

## 7. 상태를 "든다·둔다"로 뭉갠 것

`hold`, `keep`, `place`가 전부 "든다"·"둔다"로 옮겨져 한 문단에 여러 번 겹친다.

- 진행 방향을 상태로 **들고 다닌다**
- 데이터셋과 학습기를 **들고**, 직전에 쓴 자세를 기억한다
- 자세와 인식 임계만 **든다**
- 최근 N개만 메모리에 **들고 있다가**
- 데이터셋에 **든** 캐릭터
- 0.0으로 **둔다** / 느슨하게 **둔다** / `None`으로 **둔다** / 그대로 **둔다** / 읽기 전용으로 **둔다**
- 이 자리를 그대로 **두어** ... 열어 **둔다**
- 여유를 **둔다** / 간격을 **둔다** / 기준을 **둔다** / 사이로 **잡았다**
- 한 번 만들어 **둔다** / 받아 **둔다** / 모아 **둔다** / 남겨 **둔다**
- 파일이 어디 있는지를 적는 자리에도 쓴다. "목록 파일은 그 안의 `references/`에 **둔다**",
  "예시는 목록 파일에 **둔다**", "스킬 파일은 `skills/`에, 목록 파일은 그 아래에 **둔다**"

## 8. "잡는다"의 과부하

한 낱말이 서로 다른 여러 동작을 모두 맡고 있어 무엇을 하는지 문장에서 사라진다.

- 좌표를 잡는다 / 격자 원점을 잡아 / 원점을 잡는다
- 경계가 깨끗이 잡혀 / 격자를 잡은 기준 화면
- 후보로 잡고 / 계단으로 잡았다 / top-1을 잡는다
- 임계를 그 사이로 잡는다 / 하한을 잡았다
- 정수 위상과 소수부 밀림을 한 번에 잡는다 / 서브픽셀까지 좌표를 잡는다

## 9. 상투구의 반복

같은 문형이 문서 전체에 반복돼 리듬이 기계적이다.

- **~이 곧 ~다**: "삽입 순서가 곧 시간순이라", "이름 정렬이 곧 시간순이다", "착지점이 곧 상단 중앙",
  "가려진 열이 곧 계단이다", "그 스텝의 검출 프레임 겸 정지 자세 표본"
- **~라 / ~뿐이라 / ~것이라** (조사 생략 축약): "표준 위치 crop이라", "게임당 한 번뿐이라",
  "프리뷰 좌표계에서 크롭한 것이라", "ASCII 밖의 확장 코드라", "선형 탐색으로 충분하고"
- **~게 한다** (사역 남발): "알아보게 한다", "확인하게 한다", "지울 수 있게 한다", "되짚게 한다",
  "건너뛰게 한다", "빠져나가게 한다", "섞이지 않게 한다"
- **곧장**: "곧장 등반한다", "곧장 오른다", "곧장 세션을 시작하므로", "곧장 판정에 들어간다",
  "곧장 이어진다"
- **통째로**: "통째로 가린다", "통째로 다시 쓴다", "통째로 저장한다", "통째로 줄인 것", "통째로 죽는다"
- **훑는다**: "데이터셋을 훑는다", "프레임 전면을 훑어", "맨 아래 행부터 위로 훑어", "뒤에서부터 훑는다",
  "주변(±shift)을 훑어"
- **돈다 / 돌린다**: "루프를 돈다", "검출을 돌리지 않고", "확정과 계획을 다시 돌린다",
  "매칭을 돌려", "스레드로 돌린다", "제어 주기를 따라 돌아", "훅이 스스로 돈다",
  "부를 때만 도는 스킬", "리뷰 라운드를 돈다"
- **삼는다**: "관측으로 삼아", "앵커 (0, 0)로 삼아", "그 칸을 계단으로 삼아", "검출로 삼기엔"
- **되짚는다**: "되짚을 수 있어", "되짚게 한다", "프레임과 대조할 수 있게"
- **~하려는 배치다**: "S 채널이 그 둘을 구분하는지 보려는 배치다", "육안으로 확인하려는 배치일 뿐"
- **~는 자리다**: "외부 장치인 폰을 감싸는 자리다", "쓰는 자리는", "계획을 세우지 못하고 멈춘 자리의"
- **세운다**: "계획이 서면", "계획을 세우지 못하고", "이 분리가 서는지", "'안 잡힘=없음'이 서지 않으니"
- **걸린다 / 건다**: "블러를 걸어", "settle을 걸 수 없으므로", "임계를 걸지 않고", "제약을 걸지 않는다",
  "소거 보간도 걸리지 않아", "여기서 걸린다", "reverse 터널을 먼저 걸어야"
- **걸친다**: "화면에 걸치는 열", "UI가 걸친 칸", "검은 패딩에 대부분 걸친", "걸치는 서브블록 위상차"

## 10. 대상을 가리지 않는 "자리"

무엇을 가리키는지 정하지 않은 채 "자리"로 받는다. 고치는 대상이 낱말인지 문장인지, 아니면
파일 안의 위치인지가 한 낱말에 뭉개진다.

- 고칠 **자리**마다 어느 판정에 해당하는지 정한다 / 고친 **자리**와 판정 이름을 보고한다
- Claude 문체에 해당하는 **자리**를 찾아 다시 쓴다
- 그 표현이 그 **자리**에서 가장 짧고 정확한 수단이면
