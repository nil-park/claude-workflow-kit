# Claude 문체 — 낱말 단위로 걷어낼 표현 목록

사람이 쓰지 않는 문형, 직역, 지어낸 낱말, 같은 상투구의 반복이 대상이다. 개별 판단은 문맥에서
하되, 아래에 모인 것은 전부 한 번은 다시 봐야 한다.

## 영어 낱말을 그대로 옮긴 것

- **거꾸로 import한다** — `reverse`. "control을 거꾸로 import하지 않게", "character_finder를 거꾸로 알지 않게".
- **접는다** — `fold`. "소거 보간과 외삽을 접고 멈춘다", "외삽을 접는 데 쓴다".

## 의인화

무생물에 사람 동사를 붙였다.

## 설명을 대신한 비유

- **흔든다** — "coarse를 흔들어 교정을 유도할", "coarse를 흔든 뒤"
- **뭉개진다** — "S 채널이 두 번 뭉개지지 않게", "계단 형상의 뭉개짐을 줄이려고"

## "잡는다"의 과부하

한 낱말이 서로 다른 여러 동작을 모두 맡고 있어 무엇을 하는지 문장에서 사라진다.

- 좌표를 잡는다 / 격자 원점을 잡아 / 원점을 잡는다
- 경계가 깨끗이 잡혀 / 격자를 잡은 기준 화면
- 후보로 잡고 / 계단으로 잡았다 / top-1을 잡는다
- 임계를 그 사이로 잡는다 / 하한을 잡았다
- 정수 위상과 소수부를 한 번에 잡는다 / 서브픽셀까지 좌표를 잡는다

## 상투구의 반복

같은 문형이 문서 전체에 반복돼 리듬이 기계적이다.

- **~이 곧 ~다**: "삽입 순서가 곧 시간순이라", "이름 정렬이 곧 시간순이다", "착지점이 곧 상단 중앙",
  "가려진 열이 곧 계단이다", "그 스텝의 검출 프레임 겸 정지 자세 표본"
- **~가 아니라 ~다** (대조로 내리는 정의): "목록은 금지어가 아니라 다시 볼 표시다",
  "판정은 치환 지시가 아니라 판정 근거다". 아닌 쪽을 지우고 할 일만 적으면 문장이 하나로 준다.
- **~라 / ~뿐이라 / ~것이라** (조사 생략 축약): "표준 위치 crop이라", "게임당 한 번뿐이라",
  "프리뷰 좌표계에서 크롭한 것이라", "ASCII 밖의 확장 코드라", "선형 탐색으로 충분하고"
- **~게 한다** (사역 남발): "알아보게 한다", "확인하게 한다", "지울 수 있게 한다",
  "건너뛰게 한다", "빠져나가게 한다", "섞이지 않게 한다"
- **~하려는 배치다**: "S 채널이 그 둘을 구분하는지 보려는 배치다", "육안으로 확인하려는 배치일 뿐"
- **~는 자리다**: "외부 장치인 폰을 감싸는 자리다", "쓰는 자리는", "계획을 세우지 못하고 멈춘 자리의"
- **걸친다**: "화면에 걸치는 열", "UI가 걸친 칸", "검은 패딩에 대부분 걸친", "걸치는 서브블록 위상차"

## 대상을 가리지 않는 "자리"

무엇을 가리키는지 정하지 않은 채 "자리"로 받는다. 고치는 대상이 낱말인지 문장인지, 아니면
파일 안의 위치인지가 한 낱말에 뭉개진다.

- 고칠 **자리**마다 어느 판정에 해당하는지 정한다 / 고친 **자리**와 판정 이름을 보고한다
- Claude 문체에 해당하는 **자리**를 찾아 다시 쓴다
