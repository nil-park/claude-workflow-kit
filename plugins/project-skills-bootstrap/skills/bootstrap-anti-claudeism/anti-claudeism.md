# 클로디즘 걷어내기

- 텍스트에서 Claude가 한국어를 쓸 때 되풀이하는 문형을 찾아, 문맥에 맞는 한국어로 다시 쓴다.

## 대상

- 지정받은 범위 안에서만 고친다.
  - 별도 언급이 없으면 이번 작업에서 새로 쓰거나 고친 한국어 텍스트가 대상이다.
- 문서, 소스 코드 주석, 독스트링, 커밋 메시지, 이슈와 PR/MR의 제목과 설명을 모두 다룬다.

## 절차

- 아래 탐색절과 예시절을 이전 턴의 요약이나 기억으로 대신하지 않는다.
- 대상 텍스트를 처음부터 끝까지 읽는다.
  - `grep` 등의 Bash 도구로 낱말만 검색하면 문장 단위 결함을 찾기 어렵다.
- 고친 위치와 판정 이름을 보고한다.

## 탐색

- 판정은 읽어야 하는 범위에 따라 두 층위로 나뉜다.

### 문장 하나로 판정되는 것

- 주어와 서술어가 맞지 않는다
  - 주어가 없다
  - 주어를 겹쳐 놓고 서술어를 주지 않았다
  - 한 문장 안에서 주어가 바뀐다
  - 주어가 서술어의 주체가 될 수 없다
- 목적어나 행위 주체가 빠졌다
- 조사나 어미를 줄여 뜻이 흐려졌다
- 문장이 서술어로 끝나지 않는다
  - 표의 셀, 불릿의 명사구, 커밋 메시지와 PR/MR 제목은 예외다
- 피동과 명사구로 서술어를 뭉갰다
  - 영어 수동태를 그대로 옮겼다
  - 명사형으로 끊어 종결어미가 없다
  - 명사를 이어 붙인 목적어에 서술어 하나를 걸었다
  - 앞 문장의 서술어를 명사로 바꿔 다음 문장의 주어로 삼았다
- 수식 관계가 꼬여 두 번 읽게 된다
  - 관형절이 여러 겹으로 쌓였다
  - 수식어가 앞말과 뒷말 중 어느 쪽을 꾸미는지 분명하지 않다
  - `의`로 명사를 이어 붙여 관계가 사라졌다
  - `-이고`로 성격이 다른 두 절을 묶었다
- 문장 부호로 절을 이었다
  - 줄표로 두 문장을 이었다
  - 가운뎃점으로 서술구나 절을 이었다
- 한 문장이 100자를 넘는다
- 선행사 없이 지시어로 받았다
- 일반적인 동사를 쓸 곳에 비유적인 낱말을 썼다
- 무생물에 사람 동사를 붙였다

### 문서 전체를 봐야 판정되는 것

- 한 낱말이 서로 다른 동작이나 대상을 여럿 맡는다
  - 서로 다른 동작을 한 동사로 받는다
  - 서로 다른 대상을 한 명사로 받는다
- 이름이 일관되지 않는다
  - 한 대상을 여러 이름으로 부른다
  - 뜻이 다른 둘에 같은 이름을 쓴다
  - 코드에 없는 절차에 이름을 지어 붙였다
- 같은 문형이 되풀이된다
  - `~이 곧 ~다`
  - `~가 아니라 ~다`
  - `~라 / ~뿐이라 / ~것이라`
  - `~게 한다`
  - `~하려는 배치다 / ~는 자리다`
- 같은 서술어를 한 문단 안에서 되풀이한다
- 같은 내용이 여러 곳에 적혀 있고 SoT가 정해지지 않았다
- 지워도 코드에서 구현의 의도가 그대로 읽히는 서술이 남아 있다
- 계층이 나뉘지 않았다
  - 불릿으로 쪼개지 않은 산문이 이어진다
  - 한 불릿에 문장이 둘 이상 들어 있다
- 강조 표기를 남발했다
  - 불릿 머리가 모두 굵은 글씨인 경우가 여기에 해당한다

## 주의 사항

- **목록에 오른 표현이라도 그대로 쓸 때가 있다.**
  - 쓰인 문장에서 그보다 짧고 정확한 말이 없으면 의인화도 남긴다.
- **고친 결과가 목록의 다른 항목이 되지 않는지 확인한다.**
  - "낸다"를 피하다가 문단 전체가 "본다"로 몰리기 쉽다.
- **무엇으로 바꿀지는 문맥에서 정한다.**
