# .refs 스크래치 디렉터리

`<repo-root>/.refs/`는 로컬 스크래치다 — 작업을 돕지만 절대 커밋되지 않는 파일들이 있는
곳이다. PR/MR/이슈 설명을 만들거나 고칠 때 `gh`/`glab`에 넘길 본문, 저장해 둔 리뷰,
"나중에 다시 보자"는 메모에 쓴다.

- **절대 커밋하지 않는다.** 여기에 쓰기 전에 `.refs/`가 gitignore돼 있어야 한다. 아직
  아니라면 **`.gitignore`에 추가하기 전에 나에게 물어라** — 그 파일을 고치는 것은 공유
  리포지토리 설정을 바꾸는 일이고, 여기가 내가 통제하는 리포지토리가 아닐 수도 있다.
- **고유하고 내용을 알 수 있는 케밥케이스 이름을 쓴다.** 고정된 이름은 쓰지 마라 — 병렬
  세션이 덮어쓴다. 이름을 브랜치나 주제에 묶어라. 예: `pr-body-<브랜치-슬러그>.md`,
  `mr-body-<브랜치-슬러그>.md`, `followup-<주제>.md`.
- 한 작업이 파일을 여럿 만들면 그 작업 이름의 하위 디렉터리로 묶는다.
- **리포지토리 밖의 파일을 고치는 작업에는 `.refs/`가 없다.** 그때는 보조 파일을 세션
  스크래치패드에 둔다. 무관한 리포지토리의 `.refs/`에 끼워 넣지 마라. **원본 옆도
  아니다** — 그 디렉터리를 통째로 읽는 도구가 있으면(`~/.claude/agents/`처럼 `*.md`를
  전부 긁는 자리) 사본까지 설정으로 읽힌다. 스크래치패드가 없으면 나에게 물어라.
- CLI에 넘길 파일(PR/MR 본문)은 **백틱을 이스케이프 없이 그대로** 쓰고 경로를 넘긴다
  (`--body-file <경로>` / `-d "$(cat <경로>)"`). 본문을 명령줄에 직접 붙이지 마라.
