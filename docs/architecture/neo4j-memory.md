# neo4j-memory

`neo4j-memory`는 여러 에이전트가 함께 읽고 쓰는 공유 기억을 Neo4j 그래프에 저장하는 컴포넌트다.

## 노드 레이블

- `Instruction`: 지침 노드
- `Scope`: 스코프 노드

## 구성 요소

- 데이터베이스: Neo4j
  - 여러 사용자가 데이터베이스 하나를 함께 사용한다.
- 임베딩 모델: Gemini Embedding 2 (GCP Agent Platform)
  - 출력 차원: 768

## 지침 스코프

- `neo4j-memory`는 AI 에이전트 지침을 저장한다.
- 각 지침은 하나 이상의 스코프에 종속된다.

| 스코프               | 적용 범위                                                                       |
| -------------------- | ------------------------------------------------------------------------------- |
| 조직에 종속됨        | 특정 조직에 속한 모든 사용자                                                    |
| 사용자에 종속됨      | 특정 사용자                                                                     |
| PC 환경에 종속됨     | 특정 PC 환경(사용자 계정, 호스트, 셸 등. 예: `kwang@NilPark-A520M-K`, Git Bash) |
| 리포지토리에 종속됨  | 특정 리포지토리                                                                 |
| 업무 스코프에 종속됨 | 수행하는 업무의 종류                                                            |

- 모든 지침은 조직 스코프와 사용자 스코프 가운데 적어도 하나에 종속된다.
- 사용자는 조직에 소속될 수 있다.
- 스코프는 서로 겹칠 수 있다.
  - 예를 들어 지침 하나가 특정 리포지토리와 특정 PC 환경에 함께 종속된다.

## 그래프 표현

- `Instruction` 노드는 자신이 종속되는 각 `Scope` 노드와 관계로 연결된다.
  - `Instruction` 노드가 여러 `Scope` 노드와 연결되면, 연결된 스코프의 교집합에 종속된다.
