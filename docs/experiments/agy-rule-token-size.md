# agy 규칙의 토큰 크기

- 스킬 원본 템플릿을 agy의 상시 규칙으로 불러올 때, 템플릿마다 매 턴 차지하는 입력 토큰을 측정했다.
- agy 1.3.5와 `gemini-3.8-flash-medium`에서 측정했다.

## 방법

- 템플릿 본문을 프롬프트로 보내고, agy의 첫 모델 호출에서 보고된 `input_tokens`를 읽는다.
- 본문을 뺀 같은 프롬프트의 `input_tokens`를 기준값으로 삼고, 둘의 차이를 템플릿의 크기로 정한다.
- 기준값은 실행한 디렉터리의 지침과 규칙에 따라 달라진다.
  - 그래서 기준값과 측정값을 같은 디렉터리에서 연달아 측정했다.
- `input_tokens`에는 캐시에서 읽은 토큰(`cache_read_tokens`)이 들어 있지 않다.
  - 같은 프롬프트를 연달아 보내면 `input_tokens`는 약 2,000으로 줄어든다.
    - 줄어든 약 23,700토큰은 `cache_read_tokens`로 보고된다.
  - 이 문서의 측정값은 모두 `input_tokens`가 1만을 넘는 호출에서 나왔다.
    - 그래서 캐시 적중으로 줄어든 값은 섞여 있지 않다.

## 상시 규칙 예산

- 공식 문서에 따르면 전역 규칙과 `always_on` 규칙이 20,000토큰 예산을 함께 쓴다.
  - 스킬과 MCP는 별도 예산이다.
  - `AGENTS.md`는 예산에 포함해서 계산했다.
    - 공식 문서는 `AGENTS.md`를 항상 `always_on`으로 취급한다고 서술한다.

| 항목                                     | 크기(바이트) | 입력 토큰 |
| ---------------------------------------- | ------------ | --------- |
| 여섯 규칙                                | 44,051       | 약 11,400 |
| `AGENTS.md`                              | 2,206        | 약 580    |
| 전역 `~/.gemini/GEMINI.md` (작성자 환경) | 8,265        | 약 1,890  |
| 합계                                     | 54,522       | 약 13,800 |

- 합계는 예산의 약 69%다.
- 이 리포지토리에서 `AGENTS.md`와 여섯 규칙을 모두 불러온 첫 호출의 입력은 25,842토큰이었다.
  - 이 값에는 규칙 외에 agy의 기본 시스템 프롬프트도 포함되어 있다.
- 여섯 규칙은 맨 끝 제목까지 전문이 로드되어 있었다.
  - 어떤 규칙도 경로 포인터로 바뀌지 않았다.
  - 예산을 넘으면 큰 파일부터 포인터로 바뀐다.
  - 가장 큰 `anti-claudeism`도 전문이 로드되어 있었다.

## `/context`와의 차이

- 이 리포지토리에서 `AGENTS.md`와 여섯 규칙이 로드된 상태로 작성자가 연 세션의 `/context`는 합계 37.0k토큰을 표시했다.
  - 시스템 프롬프트 21.9k, 시스템 도구 11.7k, 스킬 683, 서브에이전트 686, 대화 기록 약 2.1k
- API가 보고한 첫 호출의 합계(`input_tokens`와 `cache_read_tokens`의 합)는 약 25.8k였다.
- 대화 기록을 뺀 `/context`의 항목 합계는 약 35.0k로, API가 보고한 값보다 약 9k 크다.
  - 원인은 확인하지 못했다.
- `/context`는 규칙의 크기를 항목으로 나누지 않고 시스템 프롬프트에 포함해서 표시한다.
  - 그래서 이 문서는 규칙 크기를 API가 보고한 값으로 확인했다.
